CSS 전환(transition)과 변형(transform)

- transition : CSS 속성 값이 변경될 때 그 변화를 부드럽게 보여주는 기능
- transform : 요소를 이동, 확대/축소, 회전, 기울이기 하는 기능

1. transition

- 속성 값이 바뀔 때 일정 시간 동안 부드럽게 변화
- 기본 문법
  transition: 속성 지속시간 타이밍함수 지연시간;

- 주요 속성
  transition-property : 어떤 속성에 전환을 적용할지 지정
    ┗ all(모든 속성), width, height, background-color, color, opacity, transform 등
  transition-duration : 전환 시간 / 1s (1초) = 1000ms (1밀리초)
  transition-delay : 지연 시간
  transition-timing-function : 변화 속도 방식
    ┗ 자주 쓰는 값
       ease : 기본값, 처음과 끝은 느리고 중간은 빠름
       linear : 처음부터 끝까지 같은 속도
       ease-in : 처음은 느리고 나중에 빨라짐
       ease-out : 처음은 빠르고 끝에서 느려짐
       ease-in-out : 처음과 끝은 느리고 중간은 빠름

2. transform

- 요소의 모양이나 위치를 바꾸는 속성
- 요소를 이동하거나 회전해도 문서의 원래 배치 흐름은 크게 바뀌지 않음
- 주요 함수
    rotate() : 회전
    translate() : 이동
    scale() : 확대/축소
    skew() : 기울이기

- 여러 개를 함께 사용 가능
  transform: translateX(20px) scale(1.1) rotate(5deg);

- 주의
  transform은 따로 여러 번 쓰면 마지막 값만 적용됨

(1) rotate()

    - 요소를 회전 시키는 속성
    - transform: rotate(각도);
      transform: rotate3d(x축, y축, z축, 각도);
2d 회전
3d 회전

(2) translate()

    - 요소를 이동시키는 속성
    - transform: translate(x축, y축);
    - transform: translateX(값); -> X축으로 이동
    - transform: translateY(값); -> Y축으로 이동
x,y축 이동
x축 이동
y축 이동

(3) scale()

    - 요소를 확대 및 축소시키는 속성
    - transform: scale(값);
    - transform: scale(X축, Y축);
    - 값 :  1 = 원래크기
            1보다 큰 값 = 확대
            1보다 작은 값 = 축소
확대
축소

(4) skew()

    - 요소를 기울이는 속성
    - transform: skew(x축 각도, y축 각도);
Skew
