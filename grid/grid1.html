1. CSS Grid란?

CSS Grid는 웹 페이지를 행(row)과 열(column) 기준으로 나누어 배치할 수 있는 레이아웃 방식입니다.

  • Flex는 1차원 정렬 (가로 또는 세로 중심 정렬)
  • Grid는 2차원 정렬 (행과 열을 동시 제어)
  • 전체 페이지 레이아웃, 카드 배치, 대시보드 등 복잡한 영역 분할에 유용

2. Grid 기본 구조

.container {
    display: grid;
}

부모 요소(Grid Container)에 display: grid;를 주면 자식 요소들이 Grid Item으로 배치됩니다.

3. 열과 행 만들기

.container {
    display: grid;
    grid-template-columns: 200px 200px 200px;
    grid-template-rows: 100px 100px;
}
  • grid-template-columns: 열 너비 설정
  • grid-template-rows: 행 높이 설정

8. justify-items / align-items / place-items

각 Grid 칸 안에서 아이템이 어떻게 정렬될지 지정하는 속성입니다.

  • justify-items: 가로 방향 정렬
    • stretch : 셀의 너비만큼 늘려 배치
    • start : 내용 영역 만큼만 너비를 차지하고 셀의 시작점에 위치
    • center : 내용 영역 만큼만 너비를 차지하고 셀의 가운데 위치
    • end : 내용 영역 만큼만 너비를 차지하고 셀의 끝점에 위치
  • align-items: 세로 방향 정렬
    • stretch : 셀의 높이만큼 늘려 배치
    • start : 내용 영역 만큼만 높이를 차지하고 셀의 시작점에 위치
    • center : 내용 영역 만큼만 높이를 차지하고 셀의 가운데 위치
    • end : 내용 영역 만큼만 높이를 차지하고 셀의 끝점에 위치
  • place-items: 두 속성을 한 번에 지정하는 축약형
    • place-items: align-items속성값 justify-items속성값

9. justify-content / align-content / place-content

그리드 전체 덩어리가 부모 영역 안에서 어디에 배치될지 정하는 속성입니다.

  • justify-content: 그리드 전체의 가로 정렬
    • stretch : 컨테이너의 너비만큼 늘려 배치
    • start : 내용 영역 만큼만 너비를 차지하고 컨테이너의 시작점에 위치
    • center : 내용 영역 만큼만 너비를 차지하고 컨테이너의 가운데 위치
    • end : 내용 영역 만큼만 너비를 차지하고 컨테이너의 끝점에 위치
    • space-between : 양 끝에 아이템을 배치하고 남은 여백은 동일하게 배치
    • space-around : 아이템의 좌우 여백 동일하게 배치
    • space-evenly : 아이템 사이 모든 여백 동일하게 배치
  • align-content: 그리드 전체의 세로 정렬
    • stretch : 컨테이너의 높이만큼 늘려 배치
    • start : 내용 영역 만큼만 높이를 차지하고 컨테이너의 시작점에 위치
    • center : 내용 영역 만큼만 높이를 차지하고 컨테이너의 가운데 위치
    • end : 내용 영역 만큼만 높이를 차지하고 컨테이너의 끝점에 위치
    • space-between : 양 끝에 아이템을 배치하고 남은 여백은 동일하게 배치
    • space-around : 아이템의 좌우 여백 동일하게 배치
    • space-evenly : 아이템 사이 모든 여백 동일하게 배치
  • place-content: 두 속성을 한 번에 지정하는 축약형
    • place-content: align-content속성값 justify-content속성값

11. 핵심 정리

  • display: grid; → Grid 시작
  • grid-template-columns → 열 만들기
  • grid-template-rows → 행 만들기
  • fr → 남은 공간 비율
  • repeat() → 반복 작성
  • auto-fill / auto-fit → 자동 열 생성
  • gap → 간격 설정
  • justify-items / align-items → 아이템 내부 정렬
  • justify-content / align-content → 그리드 전체 정렬
  • place-items / place-content → 축약형 정렬 속성
