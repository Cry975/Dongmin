1. grid-column-start / grid-column-end / grid-row-start / grid-row-end

.item1 {
    grid-column-start: 1;
    grid-column-end: 3;
    grid-row-start: 1;
    grid-row-end: 3;
}
  • 아이템이 시작하는 선과 끝나는 선을 각각 따로 지정하는 방식입니다.
  • 열은 세로선 번호, 행은 가로선 번호를 기준으로 합니다.
  • grid-column-start / grid-row-start : 시작선 결정
  • grid-column-end / grid-row-end : 끝선 결정

2. grid-column / grid-row

.item1 {
    grid-column: 1 / 3;
    grid-row: 1 / 3;
}
  • 시작선과 끝선을 한 줄로 줄여 쓰는 축약형입니다.
  • grid-column: 아이템이 어느 열부터 어느 열까지 차지할지 설정
  • grid-row: 아이템이 어느 행부터 어느 행까지 차지할지 설정

4. grid-template-areas / grid-area

영역 이름을 정해서 레이아웃을 더 쉽게 구성할 수 있습니다.

  • grid-template-areas : 부모 요소에 적용, 레이아웃 구조 형성
  • grid-area : 자식 요소에 적용, 자식 요소에 이름 부여
부모 요소 {
    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
}

자식요소 { grid-area: header; }

7. 핵심 정리

  • grid-column-start / grid-column-end → 열 시작선, 끝선 지정
  • grid-row-start / grid-row-end → 행 시작선, 끝선 지정
  • grid-column / grid-row → 아이템 크기 확장 축약형
  • span → 몇 칸 차지할지 간단히 지정
  • grid-template-areas → 이름으로 레이아웃 구성
  • grid-area → 자식 요소에 영역 이름 지정
  • justify-self / align-self → 특정 아이템만 따로 정렬
  • grid-auto-rows → 자동 행 높이 지정
  • minmax() → 최소/최대 범위 설정
  • auto-fit → 반응형 자동 배치
