1. 뷰포트(viewport)와 메타 태그

뷰포트란, 사용자가 현재 보고 있는 웹 브라우저 화면의 보이는 영역
화면에 보여지는 창의 크기
웹사이트는 PC 뿐 아니라 다양한 화면에서 보여지기 때문에 중요!
PC > 태블릿 > 모바일

<meta name="viewport" content="width=device-width, initial-scale=1.0">

메타 태그
(1) width=device-width : 기기의 실제 화면 너비를 기준으로 페이지 너비 맞추라는 뜻
(2) initial-scale=1.0 : 페이지가 처음 로드될 때 확대/축소 비율을 1배로 설정하라는 뜻
(3) 필요성 : 예전 웹사이트는 PC 기준으로 제작되기 때문에 기본적으로 페이지를 넓게 해석한 후 축소하려 합니다.
모바일에서 글자가 너무 작아보이거나, 화면이 축소되어 보이거나, 반응형 CSS가 의도대로 동작하지 않을 수 있습니다.

2. 뷰포트 단위

vw
뷰포트 너비의 1%
100vw = 화면 너비의 100%
50vw = 화면 너비의 반

vh
뷰포트 높이의 1%
100vh = 화면 높이의 100%
50vh = 화면 높이의 반

vmin
뷰포트 너비와 높이 중 더 작은 값의 1%

vmax
뷰포트 너비와 높이 중 더 큰 값의 1%

width: 50vw
height: 30vh
20vmin × 20vmin
4vmax

3. 미디어쿼리 (Media Query)

- 기기의 화면 크기나 조건에 따라 다른 CSS를 적용하는 기능
- 같은 웹페이지라도 기기에 따라 적절한 디자인 필요합니다.
(예) 메뉴가 PC : 가로로 길게 배치, 모바일 : 메뉴가 세로로 쌓임
이미지 4개가 PC : 이미지 한 줄, 모바일 : 이미지 1개씩 세로로 배치
글자 PC : 크게, 모바일 : 작게

@media (조건) {
    선택자 {
        속성: 값;
    }
}
