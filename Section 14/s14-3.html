float 속성

        - 요소를 왼쪽이나 오른쪽으로 띄우는 속성
        - 요소를 일반적인 문서의 흐름에서 한쪽으로 배치하고, 그 주변을 다른 내용이 감싸도록 만드는 속성
        - float: none; -> float 적용 안함(기본값)
          float: left; -> 요소를 왼쪽으로 띄움
          float: right; -> 요소를 오른쪽으로 띄움
        - float를 사용할 경우 부모 요소의 높이가 사라짐
          => 레이아웃 배치에 문제!
          => clear 속성 사용하여 float 속성 취소
        - 이전에는 float 속성을 이용하여 레이아웃 구성했으나, 요즘은 잘 사용하지 않음
          주로 flex나 grid 사용
