background-color

    - 요소의 배경색을 지정하는 속성
    - 요소의 content와 padding 영역까지 배경이 채워짐

1. 색상명

    - red, green, blue, lightgray, black 등
빨강 노랑 파랑

2. RGB

    - RED, GREEN, BLUE의 조합으로 색을 표현하는 방식
    - background-color: rgb(red, green, blue); -> 0~255
검정 흰색 빨강 초록 파랑 노랑

3. HEX

    - RED, GREEN, BLUE를 16진수 방식(0~9, a~f)으로 색을 표현하는 방법
    - background-color: #RRGGBB; -> 00(가장 약한 값), FF(가장 강한 값)
    - 같은 숫자가 반복되면 축약형 표현 가능
      (예) #ffffff = #fff , #ffcc00 = #fc0, #ccffff = #cff
검정 흰색 빨강 초록 파랑 노랑

4. HSL

    - 색상(Hue), 채도(Saturation), 명도(Lightness)를 기준으로 표현하는 방식
    - background-color: hsl(색상, 채도, 명도);
       색상 -> 0~360도
       채도 -> 0~100%
       명도 -> 0~100%
흰색 검정 빨강 초록 파랑

5. RGBA

    - RGB에 투명도(Alpha)가 추가된 방식
    - background-color: rgba(red, green, blue, alpha); -> alpha 0(투명)~1(불투명)
흰색 검정 빨강
